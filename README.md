# nikkah-accessories

Landing page for Gift Hive, a custom nikkah keepsakes brand.

Single page site: `index.html` with product photos in `img/`.

Orders go straight to WhatsApp, including a form that writes the message for the customer.

## Deploy

Netlify: drag this folder onto https://app.netlify.com/drop

GitHub Pages: Settings then Pages then Deploy from branch `main`, folder `/ (root)`.
